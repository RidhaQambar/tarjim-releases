# Tarjim releases

This repository only hosts the **installers and update information** for Tarjim, the offline English to Arabic game translator. It contains no source code.

- Latest installer: https://github.com/RidhaQambar/tarjim-releases/releases/latest/download/Tarjim-setup.exe
- A specific version: `https://github.com/RidhaQambar/tarjim-releases/releases/download/vX.Y.Z/Tarjim_X.Y.Z_x64-setup.exe`
- All versions: https://github.com/RidhaQambar/tarjim-releases/releases

Tarjim checks `releases/latest/download/latest.json` here to offer in-app updates. Each update is cryptographically signed and the app refuses anything that is not.

# إصدارات ترجم

هذا المستودع يحتوي فقط على **ملفات التثبيت ومعلومات التحديث** لتطبيق «ترجم» لترجمة الألعاب من الإنجليزية إلى العربية دون اتصال بالإنترنت. لا يحتوي على الشيفرة المصدرية.

- أحدث ملف تثبيت: https://github.com/RidhaQambar/tarjim-releases/releases/latest/download/Tarjim-setup.exe
- إصدار محدد: `https://github.com/RidhaQambar/tarjim-releases/releases/download/vX.Y.Z/Tarjim_X.Y.Z_x64-setup.exe`
- جميع الإصدارات: https://github.com/RidhaQambar/tarjim-releases/releases

يتحقق التطبيق من الملف `releases/latest/download/latest.json` لعرض التحديثات داخل التطبيق. كل تحديث موقّع رقميًا، ويرفض التطبيق أي ملف غير موقّع.
